# Agent Note: 原生 Generative UI 与扩展开关

Status: implemented

[English](2026-09-05-native-generative-ui.md) | 中文

## 问题

任务需要在同一模型上下文和持久化会话中使用类型化人工提问与可组合结果界面。独立 SDK 演示无法提供原生工具执行、人工回答延续或会话日志回放。用户也需要可恢复地停用展示插件，而不必卸载它们。

## 决策

[Generative UI bundle](../../../../showcase/generative-ui/native/README.zh.md) 在 DSH 工具服务注册 `ask_ui` 和 `present_ui`。人工提问使用现有 `userQuestions` 服务和待回答输入区载体。报告与整轮答案携带自包含的 `generativeUi` 结果元数据。会话投影通过工具 slot 和 `Generative UI` 视图渲染这些元数据。模型请求、工具执行、取消、权限检查和持久化仍由 DSH 管理。

提问输入区把当前可回答的决策放入同一轮 grilling。推荐项保持未选择。答案成为原生工具结果后，模型再选择依赖它们的问题。任务判断不授予执行权限。结果 schema 将模型限制为预编写组件所需的数据，并校验字节上限、唯一标识、图表与表格维度，以及仅限 HTTP(S) 的交付物链接。

普通对话是主要展示面。工具卡按调用 id 订阅持久化结果快照，因此未变化的执行中工具行也能在不刷新的情况下展示完成结果。提交的选择保留原始选项和勾选答案。回合投影向公共的已完成回合尾部提供成功回答轮次和最新文档快照，不随紧凑模式的过程折叠而隐藏。此低优先级尾部让位于原生文件交付面板；未加载完整的回合和已被占用的尾部仍可通过工具卡或可选结果视图查看。结构化文档区块的预览和 Markdown 下载使用同一份纯文本内容。bundle 内的主题适配 PharmaID 的浅蓝背景、白色卡片和蓝色交互，不修改 DSH 外层界面或任务记录。

独立的 [plugin-controls bundle](../../../../showcase/plugin-controls/README.zh.md) 提供已认证的设置 RPC，只向配置的 profile 补丁写入已发现扩展的覆盖项。它保留配置与注释，拒绝过期版本和繁忙 Agent，并保留编辑前备份。管理器自身和核心应用条目受到保护。主机生命周期通过 Cordis 变化；用户点击明确的刷新操作后，浏览器重新加载初始模块图。

## 考虑过的替代方案

**独立 SDK 对话。** 它可演示 AI SDK API，但会建立另一套工具目录、消息历史和继续执行管理。本决策通过原生工具与交互服务将任务接入保留在主 harness 内。

**修改 Agent 循环或已安装核心产物。** 公共工具、提问、投影、slot 和 profile 补丁 API 已提供所需行为。这两个 bundle 不要求修改这些核心实现，也不需要另起服务。

**不校验版本就编辑插件配置。** 多个设置页可能覆盖较新的操作者决定。版本检查与原子替换保留无关配置；文件锁协调管理器自身的写入者，不宣称控制任意文件写入者。

## 影响

现有模型可以生成任务特定的卡片，而非固定示例 UI。提交的答案和结果快照可随会话回放；未提交草稿仍在浏览器本地。通用业务连接器和任意生成的 JSX 不属于渲染器。自定义可执行卡片仍需已授权的原生工具。标准浏览器启动图在插件成员变更后需要刷新页面。

无需密钥的测试覆盖 schema 拒绝、问题映射、原生提交、仅结果历史回放、回合内结果、只读选择回放、安全文档导出、生命周期释放、YAML 保留、过期/并发编辑和构建后渲染快照。真实复星会话覆盖驾驶舱组合、报告、业务卡片、两轮依赖提问和刷新恢复草稿。灰蓝周报对话覆盖依次进行的单选、多选和是非题、依据提交答案生成的文档、刷新后在紧凑对话中可见的结果，以及实际 Markdown 下载。实机设置检查覆盖开关、重启持久化、未知/受保护目标和繁忙 Agent 拒绝。已有作业卡产物工作与这两个新可安装 bundle 相互独立。
