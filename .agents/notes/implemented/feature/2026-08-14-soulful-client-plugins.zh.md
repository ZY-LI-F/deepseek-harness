# Agent Note: 有灵魂的浏览器展示插件与平台世界

Status: implemented

[English](2026-08-14-soulful-client-plugins.md) | 中文

## 问题

Web Client 能精确呈现会话与工具状态，但普通用户仍会把长时间运行的工作感知为抽象的状态变化。这套展示需要有趣、可移除、无需技术知识即可理解，并且独立于持久日志。它还要提供三种可切换的 2.5D／3D 平台世界风格，同时不让 Godot 或媒体生成运行时成为浏览器依赖，并把制作媒体和私有参考与可分发运行代码分开。

## 决策

三个活跃 Client Module 通过增量 slot 接入，另有一个源码包保留但不挂载：

- `ui-pocket-buddy` 在 `shell.overlay` 中注册一个根作用域条目。它把会话摘要归纳为四种情绪，拥有持久化的外观、动态和声音偏好，并渲染经过确认的完整角色 2D 逐帧图。侧向、朝向用户和背向用户各使用 8 张透明完整身体帧，右向则镜像完整侧向序列。连续随机终点取代固定路径图，步态按真实位移推进，左右爪印也使用同一累计距离。带权的完整角色动作序列覆盖梳洗、伸懒腰、观察、睡觉、醒来、转身、点击回应、跳跃和追球，不拆分身体。任务暂停或完成后，猫咪沿一条路线走到鲸鱼女孩身边，并默认持续睡觉，直到互动或恢复任务把它唤醒。[完整角色逐帧决策](../bug-fix/2026-08-15-source-pixel-cat-free-roaming.md)记录渲染方案的原因。衣橱预览桃桃猫、云朵猫和星夜猫三种外观。
- `ui-task-garden` 在 `conversation.viewport.overlay` 中注册一个会话作用域条目。覆盖层视觉上完全透明——没有卡片背景、模糊、边框或阴影——同时通过 `ResizeObserver` 和纯圆角边框几何从当前空间派生 12–48 个顺时针槽位。经过审阅的本地 Z-Image 蓝发鲸鱼女孩位于视口左下角的固定陪伴区。每个新观察到的工具调用身份和每次权威步骤递增都会发射一朵 V21 蓝色或粉色纯花头光栅图，以更慢的节奏经过飘散、弯曲、磁吸过冲和幂等落位；随后花头中心会无间隙地直接吸附在藤蔓上，不带茎叶，2.85 秒兜底覆盖 CSS 动画结束事件缺失。花朵全部朝内：顶部下垂，底部花园向上生长并在安全线处裁切；持久底部成长会在第一步立即开放一朵，之后每完成两步再开放一朵。V22 以唯一获准的浇水立绘为身份母版，增加 22 张完整人物帧：6 帧行走浇水循环，以及各 4 帧的赏花、欢呼、跳舞、挥手。宽圆脸、两只蓝青渐变大眼、上睫毛、小猫嘴、刘海、服装与完整身体比例保持锁定；被否决的单眼脸和身份漂移实验仍留档，但运行时绝不加载。每张 V22 图片的透明主体都会独立归一化为 450 源像素高，浏览器自适应画布则限制为最高 80 CSS 像素。任务运行时，女孩与落水一起在草地上移动；水流作为移动女孩节点的子层，并跟随 6 个逐帧设定的壶嘴锚点。每隔 5.5–10 秒或花朵落位时会播放一套会话稳定的插曲动作，随后恢复浇水。完成阶段保留鞠躬—飞吻—举杯；飞吻使用 8 张统一画布与脚底基线的完整人物帧，并在肘关节主导的释放动作后出现三颗珊瑚粉爱心。
- `ui-agent-theater` 保留源码和测试供复用，但不会在 Web 中挂载其 `conversation.input.dock` 条目。照料者形象和工作中反馈由 Task Garden 负责。
- `ui-platform-worlds` 在 `conversation.viewport.background` 中注册 `platform-world`，并在 `conversation.session.header.actions` 中注册 `platform-world-switcher`。两者共同使用一个由 fiber 拥有的 `PlatformWorldRuntime`，它会持久化 `cloud-harbor`、`candy-gears` 和 `moon-coral` 中的一种，并同步更新两个位置。

对话骨架拥有这两个空间 slot。`conversation.viewport.background` 位于 transcript（文本记录）后方，`conversation.viewport.overlay` 位于其上方但保持指针穿透。两者仅为活跃会话渲染，并避开当前输入框高度。因此，空间策略由所有者集中维护，而不是在各功能包中重复。

Pocket Buddy 提供一个 `SoulAudioRuntime` 服务。它默认静音，仅在用户明确启用后创建 AudioContext，捕获音频不可用错误，并暴露五种简短的语义提示音。Garden 和 Theater 只导入它的类型，因此其浏览器包不会包含另一个插件的运行时值。较长的 Qwen3-TTS 母版保留为视频制作素材，不进入运行时载荷。

Godot 与媒体生成工具只作为创作输入，不是浏览器依赖。可分发包只内嵌归一化后的运行逐帧图、音频数据和轻量时序。原始模型输出、提示词、用户参考、研究原片、会话截图、本机路径、废弃实验、复制的知名作品素材和生成视频都不进入公开变更。

## 状态与隐私约定

Pocket Buddy 读取会话摘要中的身份和状态字段。Task Garden 读取轮次与步骤计数、`running`，以及当前运行中工具调用的稳定身份与嵌套关系；它从不读取工具名称或参数用于展示。Platform Worlds 只读取当前会话的 `running` 标志及其浏览器本地风格偏好。未挂载的 Agent Theater 在运行时不读取任何内容。

这些包都不读取消息正文、工具参数、附件、凭据或文件系统内容。它们都不会追加会话事件、改变提示词组装、调用提供方、发出遥测或影响回放。持久化用户状态仅限本地查看偏好：`skin`、`motion`、`sound` 和平台世界的 `style`。完成庆祝和动作节奏仍是组件本地的展示状态。

## 验证

纯模型、展示、持久化、可访问性和真实 `SlotRegistry` 组合测试覆盖所有活跃包；Agent Theater 保留独立测试。Pocket Buddy 验证完整角色逐帧选择、连续随机终点、按位移推进的步态时序、停靠交接、默认睡眠、完整角色动作组合和交替爪印。Task Garden 测试覆盖实际运行时间成长边界、朝内的圆角边框采样、测量密度重排、6 帧 V22 浇水循环、确定性任务插曲、嵌套工具调用与步骤飞花、V21 纯花头素材、零间隙持久吸附、鞠躬—飞吻—举杯完成序列、爱心粒子、底部花朵和能力回退。真实浏览器验证覆盖透明中央区域、左下角角色停靠区、向下垂落的顶部花朵、受裁切的底部成长、局部花环进度、采用指定脸部的 V22 动作、移动浇水、吸附花头、以肘关节为主导的飞吻、猫咪停靠与睡眠、零横向溢出、全部图片成功加载以及没有新增运行时错误。

## 考虑过的替代方案

**合并为一个“可爱模式”包。** 否决，因为删除或替换一种展示会同时移除无关行为，而且该包需要理解多个彼此独立的 slot 接口。

**在会话事件中增加展示字段。** 否决，因为绘制意图不属于持久日志；回放与模型历史保持与展示无关。

**把 Godot 或渲染视频放入浏览器插件。** 否决，因为环境场景和页面宠物需要轻量的交互动作。Godot 继续作为可复现的创作源，浏览器仅渲染运行时需要的几何体与画面。

**使用固定尺寸的装饰花园卡片。** 否决，因为对话视口会随侧边栏、详情面板、输入框和窗口尺寸变化。测量后的归一化边框进度无需硬编码边框盒子，也能保持从左上到右侧的生长顺序。

**使用切片骨骼或程序化 3D 猫咪。** 否决，因为扁平插画不存在被四肢遮住的像素，而现有 3D 网格又无法保持已确认的角色形象。经过确认的完整角色逐帧图能让移动和表情动作中的身体结构与外观保持一致。

**采用可识别的平台游戏风格。** 否决。场景把横向滚动移动作为类型惯例，但使用原创角色、名称、轮廓、调色板、道具、收集物、几何体和声音。

**在插件中加入录制或分享控件。** 否决，因为传播产物是一支独立的讲解视频。捕获规划以及私有或受版权保护的制作输入保留在产品包和公开变更之外。

## 后果

每种活跃展示都可以独立组合、移除、测试或替换，而无需改变 agent loop（智能体循环）。合并后的照料者场景避免多个进度面板互相竞争，四足页面猫则提供有趣的跨屏信号。用户可以通过一个标题栏控件切换三种原创的平台游戏式场景。日志、提示词、模型请求与缓存行为保持不变。

这些取舍是有意的。未知工具使用通用工作坊场景；缺少 `sessionStats` 的部署看到窗口作用域的花园进度；音效是简短的可选提示；背景世界是动画画面而非可玩游戏。Pocket Buddy 内嵌经过确认的完整角色逐帧与音频数据，使浏览器包增大，换取稳定身体结构、丰富动作和已确认的插画角色身份。Task Garden 内嵌任务动作、飞吻、花朵、藤蔓、草地和爱心运行数据，并拥有有界的临时飞花、吸附花朵和动作状态，但不增加持久化展示数据。公开变更排除原始生成源和制作研究，因此制作新的素材组需要另行授权的创作工作区。
