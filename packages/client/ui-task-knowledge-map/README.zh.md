# @deepseek-ai/dsh-client-ui-task-knowledge-map

[English](README.md) | 中文

Task Knowledge Map 为 DSH Web 新增一个只读的 `conversation.view` 标签页。它把当前 Session 投影成从左到右的执行图，节点包括根 agent、Turn、Step、工作流阶段、委派的 subagent 和嵌套工具调用。已完成、执行中、等待、失败、当前路径和并行活跃路径各有明确的视觉状态。选择节点会把信息检查器切换到对应执行位置；点击**跟随当前**会重新选择实时叶节点。

执行图只使用现有 Client 快照：Chat 时间线确定 Turn 和 Step 的顺序，组装后的 `workflow-run` 与 `tool-call` 行确定分支和工具树，`runningCalls` 补充尚未产生组装行的实时调用，Session 目录提供父会话可见的 subagent 摘要。最深的活跃节点类型获得唯一当前位置标记，同时活跃的所有叶节点路径都会保持高亮。执行图最多保留 56 个工具节点，知情信息最多保留 160 条，并明确显示截断数量。

“知情位置”指在所选序列边界上，Session 中可观测且可追溯的信息，并不代表模型私有的认知状态。检查器会分类展示用户要求、注入上下文、MemOS 结果等记忆召回、工具证据、可见的 assistant 结论、上下文压缩（context compaction）、异常与重试、排队中的上下文和委派任务。推理（reasoning）块不会展示。最新压缩检查点之前的信息仍然可见，但会标记为“已压缩”；排队信息只出现在实时尾部。委派的 subagent 只展示父 Session 可见的任务和元数据，因为该视图不会打开或合并子级 transcript（文本记录）。

该包不拥有持久状态、Remote 方法、Host 行为、事件、提示词或工具。刷新和回放都会从权威快照重建同一投影；插件 dispose（资源释放）时会移除标签页和本地化词典。

## 模型体验

### 仅浏览器端的可观测投影

#### 模型看到的内容

无。Task Knowledge Map 只在请求执行后读取已经渲染的 `ConversationSnapshot` 与 `SessionListState` 值。它不会添加系统提示词、上下文项目、工具 schema、工具结果或模型消息。

#### Token 影响

无。该视图不会添加、删除或重排请求 token。

#### KV Cache 影响

无。该包从不参与提示词组装，因此不会改变可复用前缀或追加式后缀。

## 已知限制和后续工作

- 地图只覆盖当前已加载的 Session 窗口，不会猜测尚未加载的早期历史。
- 父级可见的委派元数据无法展示 subagent 的内部路径或知情状态；打开子级快照和跨 Session 导航属于独立能力。
- 可观测来源能够展示哪些信息进入了 Session、记录在何处，但不能证明模型理解、保留、相信或使用了什么。
- 自动布局是有界的树视图，不是通用执行图编辑器；当前不包含拖拽平移、小地图、导出和持久化手工位置。
