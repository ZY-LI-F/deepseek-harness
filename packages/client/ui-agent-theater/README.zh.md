# @deepseek-ai/dsh-client-ui-agent-theater

[English](README.md) | 中文

Agent Theater 是一个未挂载的浏览器展示实验。部署方显式把它加入 Web bundle 后，它会在 `conversation.input.dock` 中加入一条微型装配办公室：原创蓝色鲸鱼女孩拿着锤子沿轨道移动，并逐字敲出 `DEEPSEEK`；发生错误时则故意显示 `DEEPDEEK` 和 `干杯！` 提示。

它的纯场景模型把现有会话事实归纳为空闲、思考、终端工作、Web 工作、通用工具、审批、错误和完成等少量视觉状态。工具分类使用稳定的名称族，未知名称会回退到通用场景。组件只读取标准会话 hook，不扫描日志；敲击节奏和完成时序保留在本地。声音提示使用 Pocket Buddy 的可选音频服务，并默认静音。

标准 Web 配置不会挂载这个包。当前照料者体验由 Task Garden 负责，因此普通用户不会同时看到两个相互竞争的进度场景。

## 模型体验

### 仅浏览器端的只读模型

#### 模型看到的内容

无。Agent Theater 只有在显式挂载到 `conversation.input.dock` 后才读取现有浏览器投影；它不会注册提示词、上下文、工具 schema 或工具结果。

#### Token 影响

无。该包不会增加、删除或重排模型请求 token。

#### KV Cache 影响

无。该包从不参与提示词组装。

## 已知限制与后续工作

- 标准 Web 配置不会挂载这个包。
- 工具分类依赖名称；已知名称族之外的部署专用名称会使用通用工具场景。
- 舞台只展示当前根工具调用；嵌套 Code Mode 调用不会创建独立角色。
- `DEEPDEEK` 是错误状态下的刻意玩笑，成功状态不会显示这个拼写。
