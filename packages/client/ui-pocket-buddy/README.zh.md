# @deepseek-ai/dsh-client-ui-pocket-buddy

[English](README.md) | 中文

Pocket Buddy 是一个仅在浏览器运行、根作用域的 `shell.overlay` 页面宠物。它把现有会话列表归纳为四种视觉情绪（`idle`、`working`、`needs-you`、`celebrate`），并让用户在三种经过视觉预览的原创外观之间选择：桃桃猫、云朵猫和星夜猫。桃桃猫使用以已确认角色原画为身份锚点制作的透明完整角色动画帧：侧向、朝向用户、背向用户各 8 帧。每一帧都是重新绘制的完整猫体；运行时不再切出或单独旋转任何肢体，因此行走不会露出缺失的遮挡像素、断开的接缝或重复脚掌。

自主移动会在一个连续的屏幕安全矩形内采样任意坐标，不包含定点列表或路径图。逐帧控制器让角色以每秒 64 像素的恒定速度前进，并根据真实累计位移选择 8 张步态帧，每移动 72 像素完成一次循环。因此，脚步只会在猫咪真实前进时切换；停下后固定在同一套角色的第一张完整帧。移动向量会选择左、右、朝向用户或背向用户四种最接近的绘制方向，不再让侧面猫斜着漂。改变方向时先播放整猫缓冲，再继续前进。左右爪印只在真实步态落脚点生成，并在猫咪身后淡出。

当前任务暂停或完成后，控制器会中断随机巡游，按实时视口尺寸计算左下角鲸鱼女孩右侧的停靠点，并让猫咪沿一条直接路线真正走过去；窄屏尺寸与花园插件的响应式女孩尺寸保持一致。到达后猫咪面向女孩、自然趴下并退出行走状态。驻留日程以持续呼吸的睡眠为默认和主动作，间歇播放舔爪、洗脸、伸懒腰、观察、点击回应和原地小跳；每次互动前先完整醒来，结束后重新趴下入睡。会造成离位的自由巡游与追球不会自动触发。任务恢复后，猫咪从睡眠中醒来，再从停靠点走回连续随机活动区。关闭动态效果时则直接安静停靠，避免假装行走。

空闲表演包含 7 个语义动作：洗脸、舔爪、伸懒腰、观察、蹲坐、睡觉和追球。编排器采用带权无放回排列，以双动作居多、少量三动作；约束前理论空间为 `P(7,2)=42`、`P(7,3)=210`。姿态编译器只插入已确认的完整猫体过渡：连续坐姿动作只坐下一次，中间用坐姿闭眼停顿衔接，整组结束后再起身。洗脸明确播放两轮；睡眠包含趴下、呼吸、漂浮 Z 文字和醒来。最近 4 个动作会进入冷却，睡眠只能收尾，单段自主表演不超过 18 秒。

每张已确认的动作帧及换肤位图都会根据透明像素中的猫咪轮廓分别归一化；最长可见边固定为 100 个 CSS 像素，且不随页面宽窄再次缩放，桃桃猫动作帧还共用同一条脚底线。换肤、站立、梳洗、睡觉以及 12 帧追球动作之间因此保持稳定的视觉体型，同时不会缩短屏幕移动距离或让脚掌离开落脚线。

状态气泡使用同一个 100 像素可见轮廓作为锚点，而不是明显更高的角色外框。无论宽屏还是窄屏，它都会水平对准猫咪头部，并只保留 4 像素间距，因此动作帧切换时“正在认真上班”也始终贴近角色。

外观、动态和声音偏好使用 slot 存储的本地持久化；衣橱开关状态保留在组件本地。声音默认静音。用户明确启用后，`SoulAudioRuntime` 优先播放两条内嵌的 0.56／0.80 秒 Qwen3-TTS 角色音，失败时才回退到短 Web Audio，并执行 30 秒全局猫叫冷却；运行时不发起网络请求。

插件只读取会话摘要标志。它不检查对话内容、不追加事件、不调用模型，也不发起网络请求。卸载其 fiber 会移除覆盖层、词典、存储位置和延迟创建的音频上下文；持久化的查看偏好会保留，供以后重新安装时使用。

## 模型体验

无，因为这个浏览器侧覆盖层只读取现有 Client 投影，不注册任何面向模型的内容。

#### KV Cache 影响

无；它既不组装也不发送模型请求。

## 已知限制与后续工作

- 三种外观只改变页面宠物，不改变应用全局调色板或 Platform World。三种外观都使用经过确认的完整身体位图序列；桃桃猫的第一张行走帧也作为静止形象。
- 桃桃猫目前使用侧向、朝向用户和背向用户三套 8 帧步态；右向由完整侧向帧镜像得到。四种方向覆盖自由漫游的主要屏幕朝向。
- 公开包只包含完整角色 2D 运行链路。原始参考素材、原 Three.js 渲染器以及废弃的切片或 3D 实验仅保留在本机，不进入公开分支和浏览器构建。
- 行走、梳洗、伸懒腰、睡眠、扑球、观察、点击回应和转身都使用经过确认的完整身体帧。新增表情仍需补充完整帧序列；运行时不会从扁平插画中合成不存在的遮挡结构。
- 眼睛和耳朵已烘焙在每一张完整身体帧里。独立表情需要新的、经过确认的完整帧序列，而不是再次切割扁平原图。
- 完成提示文字仍会短暂显示；猫咪本体优先完成“走到女孩身边—趴下—持续睡觉”的收尾，不会用定点庆祝姿势阻断返程。
- 两条运行时猫叫是合成的 Qwen3-TTS 角色音，不是真实录音或音色克隆。它们保持可选、低音量、低概率和全局冷却；睡觉时不会叫。
