# DeepSeek Harness 灵魂感 UI 插件

[English](README.md) | 中文

Web 配置挂载了三个相互独立的展示插件，让普通用户更容易感知长任务的进展，同时不改变智能体、提示词或工具。它们只使用浏览器已有的会话投影，并且都可以通过常规 Cordis 插件配置移除。

## 包含内容

| 插件 | 用户体验 | 挂载位置 |
|---|---|---|
| Pocket Buddy | 一只完整角色逐帧制作的 2D 桃桃猫会在页面自由活动、留下渐隐爪印，并响应点击、洗脸、伸懒腰、追球；任务暂停或完成后，它会到鲸鱼女孩身边睡觉。云朵猫和星夜猫是可选外观。 | `shell.overlay` |
| Task Garden | 蓝发鲸鱼女孩在一小片草地上来回浇水，贴着页面边缘的花藤会随任务实际运行时间生长。工具调用和步骤进度会发射花头，花头漂向藤蔓并直接吸附。 | `conversation.viewport.overlay` |
| Platform Worlds | 顶部控制项可在云港跳岛、糖果齿轮城和月光珊瑚湾之间切换；选中的 2.5D 或 3D 风格场景始终位于对话内容后方。 | `conversation.viewport.background` 和 `conversation.session.header.actions` |

`ui-agent-theater` 包作为未挂载的实验代码保留。它的办公长条不会出现在 Web 配置中；当前工作反馈统一由 Task Garden 的照料者承担。

## 互动与进度

Pocket Buddy 使用完整身体逐帧图，而不是切片骨骼。侧向、朝向用户和背向用户的步态会沿当前视口中的连续随机终点移动，并根据真实位移推进动画帧，因此猫咪停下时脚不会继续空走。猫咪到鲸鱼女孩身边后默认持续睡觉；互动前会醒来，结束后重新趴下。动态与声音都可以关闭，声音默认静音。

Task Garden 会测量整个页面，不假设固定的对话栏尺寸。一圈花藤用十分钟实际任务时间沿自适应页面边缘闭合，并从萌发开始保留三十分钟，因此最多同时叠加三圈。蓝色和粉色花头不带茎叶、无间隙地吸附在藤蔓上；底部生长不会越过输入框，中间区域保持透明并允许点击穿透。

Platform Worlds 只把选中的风格保存在浏览器本地。场景动画刻意保持轻量，并遵循系统的减少动态效果偏好。

## 隐私

这些插件不会读取消息正文、工具参数、附件、凭据、环境变量或文件系统内容，也不会追加会话事件、改变提示词组装、调用模型、发送遥测、上传媒体或发起运行时网络请求。

插件仅在本地持久化猫咪外观、动态、声音和平台世界风格等查看偏好。任务进度来自浏览器已经拥有的会话摘要与投影字段。

公开变更只包含应用代码和浏览器运行所必需的生成后图片或音频数据；原始模型输出、生成提示词与日志、用户参考图、研究原片、会话截图、本机源路径和废弃的 3D 实验均明确排除。

## 从源码运行

需要 Node.js `^22.19.0 || >=24.0.0` 和 pnpm `11.7.0`。

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm run build
pnpm dsh web
```

打开 `http://127.0.0.1:3080`。这个分支的 Web bundle 配置已经包含三个启用中的插件。
